# Project context

This repository builds a B2B multi-tenant FinOps and AI governance SaaS. The MVP focuses on OpenAI, Anthropic and Vertex AI costs/usage and manually managed/imported corporate licenses. It is not an AI gateway and it does not retain prompts or model responses.

Follow `AGENTS.md`, use the documented Git workflow in `docs/git-workflow.md`, and treat provider credentials and tenant data as sensitive.
